# Service Ticket System

The Service Ticket System makes it possible for customers to log an issue with heading and query including customer name, email and date. Logged service tickets can then be searched, updated and deleted once query has been resolved. This system will help document service queries.

## Table of Contents

* [Installation](#installation)
* [Usage](#usage)
* [Credits](#credits)

## Installation

Copy all files in the folder \source_code in one designated folder.

## Usage

Open `main.py` and run the code. You will be greeted by the main menu. Choose from the options listed to add, search, print, change, and delete completed tickets. Each option will guide the user for specific actions. To exit the program, use the exit option.
